# Slime Kingdom

A 2D incremental arena game about defeating slimes, earning gold, and building automated defenses.

## Overview

The game takes place in a square arena populated by wandering slimes. The core loop is:

**Attack slimes &rarr; earn gold &rarr; buy defenses and upgrades &rarr; increase damage output &rarr; buy the kingdom.**

The target playtime is approximately 15 minutes.

## Technology

- Unity 6
- C#
- Universal Render Pipeline (URP) with the 2D Renderer
